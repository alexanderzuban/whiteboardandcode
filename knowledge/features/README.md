# Feature Documentation

This folder contains technical documentation for implemented features including architecture, APIs, and usage.

## Contents

- `drawing-system.md` - Core drawing system architecture
- `shapes.md` - Shape implementations and APIs
- `operations.md` - Drawing operations (pan, select, erase, etc.)
- `state-management.md` - Redux store and persistence
- `text-editor.md` - Monaco editor integration

## Documentation Standards

Each feature document should include:
1. **Overview** - What the feature does
2. **Architecture** - How it's structured
3. **Key Files** - Important source files
4. **API** - Public interfaces and types
5. **Usage Examples** - How to use/extend the feature
