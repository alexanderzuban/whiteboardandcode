# Prompts - 2026-01-01

## Session 1

### Prompt 1
> review drawing features to improve missing elements, and improve visual appearance

**Outcome:** Reviewed and fixed critical drawing system issues:

1. **Fixed Critical roundRect() Bug** (`packages/client/src/Drawing/Operation/Hover/operation-hover-painter.ts`):
   - Replaced `context2d.roundRect()` (poor browser support) with path-based `drawRoundedRect()` helper
   - Uses `arcTo()` for cross-browser compatible rounded corners
   - Prevents crashes in browsers without roundRect support

2. **Fixed Selection Painter Coordinate Inversion** (`packages/client/src/Drawing/Painter/selection.ts`):
   - Corrected variable naming: `minX`/`minY` for topLeft, `maxX`/`maxY` for bottomRight
   - Fixed confusing inverted naming that made code harder to maintain

3. **Fixed Resize Bullet Centering** (`packages/client/src/UI/Drawing/SelectionEditor/selection-resize-bullet-view.tsx`):
   - Added `BULLET_SIZE` and `BULLET_OFFSET` constants
   - Bullets now centered on corner coordinates by offsetting by half size (8px)
   - Added `color` from theme and `pointerEvents: "none"` for proper styling

4. **Added lineCap/lineJoin for Smoother Lines** (`packages/client/src/Drawing/Shape/drawig-shape-painter-base.ts`):
   - Added `context2d.lineCap = "round"` and `context2d.lineJoin = "round"`
   - Applies to all shapes using the base painter
   - Smoother freehand, polyline, and line rendering

5. **Fixed npm Workspace Protocol** (`packages/client/package.json`, `packages/server/package.json`):
   - Changed `"workspace:*"` to `"*"` for npm compatibility
   - `workspace:*` is pnpm/yarn syntax, npm uses `*` for local workspace dependencies

6. **Fixed TypeScript Config** (`packages/client/tsconfig.json`):
   - Removed `vite.config.ts` from main tsconfig include
   - Vite config is handled separately by `tsconfig.node.json`
