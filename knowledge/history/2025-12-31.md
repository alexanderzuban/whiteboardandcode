### Prompt 3
> The project goal is to provide an easy collaboration environment with ability to write code/use whiteboard and modeling tools. Right now it is hosted on AWS serverless platform. reorganize it in a way that backend can be added to it. suggest which backend framework will be the best/cheapest option, so based on this reorganize this repo structure to include/define backend/frontend/infrastructure

**Outcome:** Reorganized project into monorepo with backend and infrastructure support:

1. **Backend Framework Decision:**
   - Recommended **Fastify + AWS Lambda** (Node.js/TypeScript)
   - Reasons: Same language as frontend, fastest Node.js framework, native TypeScript, excellent serverless support
   - Cost-effective: Pay-per-request Lambda + DynamoDB

2. **Monorepo Structure Created:**
   ```
   packages/
   ├── client/           # React frontend (moved from client-ui)
   ├── server/           # Fastify API scaffold
   ├── shared/           # Shared TypeScript types
   └── infrastructure/   # AWS CDK stacks
   ```

3. **Backend Package (packages/server):**
   - Fastify app with AWS Lambda adapter
   - Document CRUD API routes
   - Health check endpoint
   - In-memory store (DynamoDB ready)

4. **Shared Package (packages/shared):**
   - Document types
   - Drawing types
   - API request/response types
   - Common utilities (Point, Rect, etc.)

5. **Infrastructure Package (packages/infrastructure):**
   - AWS CDK with TypeScript

6. **Root Configuration:**
