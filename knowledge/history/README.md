# Prompt History

This folder contains a log of all prompts sent to Claude, organized by date.

## File Naming Convention

Files are named by date: `YYYY-MM-DD.md`

Example: `2025-12-31.md`

## File Format

Each prompt entry includes:
- Timestamp (if available)
- The prompt text
- Brief summary of the outcome/changes made

## Purpose

- Track the evolution of the project
- Provide context for future Claude sessions
- Document decisions and rationale
- Enable review of past interactions

## Maintenance

- Add new prompts to the current day's file
- Create a new file for each day with prompts
- Keep prompts in chronological order within each file
